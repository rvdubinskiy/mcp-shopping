# MCP Shopping

Локальный MCP сервер для ChatGPT, который выполняет поиск товаров на [Yandex Shopping](https://yandex.com/shopping) с прицелом на турецкий рынок и возвращает карточки предложений в стиле Google Shopping.

## Возможности

- MCP-инструмент `search_yandex_shopping` выполняет HTTP-запрос на поисковую выдачу Yandex Shopping.
- Сервер отбирает результаты для региона Турции (по умолчанию — Стамбул) и аггрегирует ключевые поля: цену, продавца, рейтинг, доставку и ссылки на изображения.
- Возвращает как структурированные JSON-данные, так и ASCII-карточки в стиле Google Shopping, удобные для отображения в ChatGPT.
- В комплект входит CLI на TypeScript, который демонстрирует использование инструмента и умеет работать как через MCP, так и напрямую через библиотеку поиска.

## Установка

```bash
npm install
```

> ⚠️ Пакеты `@modelcontextprotocol/sdk`, `undici`, `cheerio` и `zod` публикуются в npm. Убедитесь, что у вас есть доступ к реестру.

## Сборка

```bash
npm run build
```

После сборки будет доступен сервер (`dist/server.js`) и клиент (`dist/client.js`).

## Запуск MCP сервера

```bash
npm run start
```

Сервер экспортирует инструмент `search_yandex_shopping`. Его можно подключить к ChatGPT через Model Context Protocol или использовать напрямую.

## Демонстрационный CLI

```bash
# В режиме разработки (использует tsx)
npm run dev:client -- "iPhone 15" 6

# После сборки
npm run build
npm run client -- "iPhone 15" 6
```

CLI спросит запрос и лимит, если они не переданы параметрами. В первую очередь он пытается вызвать MCP сервер через stdio. Если сервер недоступен, выполнит прямой поиск через библиотеку `searchYandexShopping` и все равно отрисует карточки.

## Структура проекта

- `src/lib/yandex.ts` — логика поиска и парсинга выдачи Yandex Shopping.
- `src/lib/cardRenderer.ts` — генерация ASCII-карточек с результатами.
- `src/server.ts` — MCP сервер и регистрация инструмента `search_yandex_shopping`.
- `src/client.ts` — CLI, показывающий, как подключиться к серверу.
- `src/types/mcp-sdk.d.ts` — минимальные декларации типов для SDK MCP (облегчают сборку без официальных типов).

## Переменные окружения

- `MCP_YANDEX_REGION` (опционально): можно переопределить регион Yandex `lr` для поиска. Реализуйте кастомную логику при необходимости, передав значение в `search_yandex_shopping`.
